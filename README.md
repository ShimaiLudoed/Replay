# Replay System

## 🎮 Управление (кнопки)

| Кнопка | Горячая клавиша | Что делает |
|--------|----------------|-------------|
| **Start Recording** | `F1` | Начать запись |
| **Stop Recording** | `F2` | Остановить запись |
| **Play Last Replay** | `F3` | Воспроизвести последнюю запись |
| **Save Replay** | - | Сохранить в файл |
| **Load Replay** | - | Загрузить из файла |

## ⚙️ Как работает

1. Нажимаете **F1** → система начинает записывать ваши действия (движение, прыжки, атаки)
2. Играете 10-30 секунд
3. Нажимаете **F2** → запись останавливается
4. Нажимаете **F3** → игра сама повторяет всё, что вы делали

## 🎯 Seed

- Seed показывается на экране во время записи
- При сохранении файл называется `replay_seed_{seed}.replay`
- Чтобы загрузить реплей - введите seed и нажмите Load
